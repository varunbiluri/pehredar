# Pehredar v1.0.0-beta.3

This localization-quality beta removes the remaining English-only interface sections and makes the complete visible UI available across all 22 scheduled Indian languages.

## Improvements

- Complete localization of setup, protection, privacy, safety, and language-support content.
- Shorter controlled source copy to reduce ambiguity in translation.
- Explicit Android per-app locale metadata for English plus 22 Indian languages.
- Reproducible offline IndicTrans2 translation workflow.
- CI quality gates for missing strings, blank strings, English fallback, Unicode normalization, RTL content, and Santali script contamination.
- Documented two-native-reviewer process for production linguistic approval.

## Scope

Pehredar checks whether incoming numbers are saved contacts. It does not listen to call audio, so screening behavior is independent of the caller's spoken language.
