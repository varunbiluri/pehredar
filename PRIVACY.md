# Pehredar Privacy Policy

Effective date: 16 August 2026

Pehredar is designed to work entirely on your Android device.

## Data used by the app

Pehredar requests access to your contacts only to determine whether an incoming phone number belongs to a saved contact. The app does not copy, upload, sell, or share contacts.

The optional AI Lab requests microphone access only when the user taps its
listen button. It sends microphone input only to Android's explicitly on-device
speech recognizer on supported phones. Pehredar does not save audio,
transcripts, classifications, or suggested replies. Typed text is analyzed in
memory, and spoken output uses an installed TTS voice that does not require a
network connection.

Android provides incoming call information to Pehredar after the user explicitly selects it as the device's call-screening app. Pehredar uses that information transiently to decide whether an unknown caller should ring silently. It does not record calls, access call audio, maintain a call database, or transmit phone numbers.

## Network and accounts

The Android application does not request internet access, contain advertising, require an account, or operate a backend service.

## Local settings

The protection preference is stored locally in Android private application storage. Application backup is disabled. Uninstalling the app removes this preference.

## User control

Users can disable protection inside Pehredar, revoke contacts or microphone
access, replace Pehredar as the system call-screening app, or uninstall the app
at any time.

## Contact

Privacy questions and security reports may be submitted through the repository's GitHub Issues page.
