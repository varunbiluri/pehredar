# Support

Pehredar is community-supported software without warranties or guaranteed
response times.

- Bugs and reproducible device problems: use the bug-report issue form.
- Translation corrections: use the translation issue form.
- Feature proposals: use the feature-request form or GitHub Discussions.
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md), never issues.
- General questions and ideas: use GitHub Discussions.

Before asking, check the README, existing issues, release notes, and your
device's Android version. Include Pehredar version, device manufacturer/model,
Android version, and dual-SIM status. Redact all phone numbers and personal data.
